# 🗄️ Sistema de Gerenciamento de Banco de Dados (SGBD)

Bem-vindo(a) ao repositório do meu projeto de **Sistema de Gerenciamento de Banco de Dados**, desenvolvido como um desafio prático para consolidar meus conhecimentos em modelagem relacional, implementação física de bancos e comandos SQL.

---

## 📌 Objetivo do Projeto

Construir um sistema de banco de dados completo, passando por todas as etapas essenciais:

- Modelagem lógica com identificação de entidades, atributos e relacionamentos.
- Conversão para modelo físico com foco em desempenho.
- Implementação e manipulação dos dados com SQL.
- Testes e validações para garantir integridade e performance.

---

## 🚀 Principais Aprendizados

### 1️⃣ Compreensão Profunda do Modelo Relacional
Aprendi a modelar dados de forma eficiente e segura, usando diagramas E-R para representar o domínio do problema com clareza.

### 2️⃣ Tradução do Modelo Lógico para o Físico
Implementei estratégias como:
- Criação de **índices** para acelerar consultas;
- Avaliação de **particionamento** para escalabilidade;
- Otimização de **consultas complexas** com foco em performance.

### 3️⃣ Domínio Prático de SQL
Aprofundei meus conhecimentos em:
- Comandos básicos: `SELECT`, `INSERT`, `UPDATE`, `DELETE`;
- Comandos intermediários/avançados: `INNER JOIN`, `LEFT JOIN`, subconsultas, `GROUP BY`, `HAVING`;
- Conceitos de **transações**, **integridade referencial** e **normalização**.

### 4️⃣ Testes e Melhorias Contínuas
Utilizei testes frequentes para:
- Verificar integridade dos relacionamentos;
- Identificar e corrigir erros de lógica ou performance;
- Garantir a estabilidade do banco.

---

## 🛠️ Tecnologias Utilizadas

| Ferramenta       | Finalidade                                |
|------------------|--------------------------------------------|
| **Power Architect** | Modelagem física e geração do script SQL |
| **BrModelo**        | Criação do modelo lógico relacional       |
| **WampServer**      | Execução local do banco de dados          |
| **SQL Workbench**   | Interface para execução e testes de SQL   |
